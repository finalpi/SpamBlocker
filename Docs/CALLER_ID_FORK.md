# 来电分类增强版

基于 aj3423/SpamBlocker v5.20，增加独立的电话分类显示。API 返回的银行、快递、营销等标签可用于浮窗显示，缺少分类时显示“未识别类型”。默认浮窗采用深色背景、大号分类文字和分类颜色。分类展示与拦截判定分别处理。

新增模板变量 `{category}` 和 `{category_color}`。明确骚扰标签用红色，已识别名称用蓝色，未知类型用橙色。已有的 `{reason}`、`{geolocation}`、`{carrier}` 仍可使用。导入上游默认模板后会自动迁移到增强样式，自定义模板可手动添加新变量。

启用来电浮窗时，拦截来电也会显示分类，浮窗最多 4 秒后收起。接听或通话结束时，浮窗按通话状态收起。

APK 文件名为 `app-release.apk`，应用名称为“骚扰拦截 / SpamBlocker”，包名为 `spam.blocker`，最低支持 Android 10。此 fork 使用独立签名。安装前先从官方版导出配置，再卸载官方版、安装此 APK，并导入配置。在系统默认应用设置中选择“骚扰拦截”作为来电识别应用，授予悬浮窗和电话状态权限，并启用来电浮窗。

号码类型取自识别来源。未取得标签的号码显示为未识别，首次查询超时的来电可能在该次通话中缺少分类。

APK 由 GitHub Actions 构建，使用此 fork 的独立固定签名。发布附件包含安装包、SHA-256、签名证书摘要和对应源码提交信息。
